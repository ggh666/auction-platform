# 系统用户手册

本文是游戏资产交换平台的系统用户手册，覆盖小程序端和后台管理端的主要功能、操作流程、角色权限、业务规则和常见问题。

平台定位：本系统只提供游戏资产信息展示、审核、关注、出价、结果记录和运营管理能力，不提供线上支付、担保、交付、私信、评论或联系方式交换。用户达成交换意向后的资金与交付安排不在本系统内完成。

## 适用对象

| 对象 | 使用入口 | 主要职责 |
| --- | --- | --- |
| 小程序用户 | 微信小程序 | 登录、浏览交换信息、发布资产、上传图片、关注信息、提交估价、查看消息和个人记录 |
| 主理人 | 管理后台 | 审核自己名下资产、处理自己名下举报、查看自己名下数据、必要时下架或扣减信誉分 |
| 运营人员 | 管理后台 | 查看资产数据、导出数据、下架违规或异常资产 |
| 超级管理员 | 管理后台 | 全量数据管理、后台账号管理、主理人管理、前台用户风控、系统配置维护 |

## 核心概念

### 资产

资产是用户发布的交换信息，当前支持：

- 账号
- 道具
- 道具下的龙珠分类

资产会记录游戏名称、区服、类型、标题、描述、图片、起始价、最低加价、当前价、状态、主理人和截止时间。

### 主理人

主理人是资产归属和运营处理人的概念。小程序用户发布信息时必须选择主理人。后台登录用户可以绑定一个主理人，绑定后该后台用户只能查看和处理自己名下的数据。

超级管理员可以查看全部数据，包括没有主理人归属的历史数据。

### 信誉分

小程序用户默认信誉分为 100 分。主理人或超级管理员在审核具体违规资产时，可以对该资产发布者扣减 5 分信誉分。

规则：

- 每次扣减 5 分。
- 信誉分 70 分及以下时，用户只能浏览，不能发布、上传资产图片、关注、取消关注、出价、举报或标记通知已读。
- 扣分满 3 个月后，系统会在用户读取或写操作校验路径自动恢复为 100 分。
- 信誉分只和用户账号有关；违规公示标签只展示在具体违规资产上，不扩散到该用户所有资产。

### 封禁

后台可以封禁小程序用户。封禁后，即使用户仍持有旧登录态，也不能发布信息、上传资产图片、出价或提交举报。

### 内容安全

生产环境会接入微信官方内容安全：

- 文本：资产发布和举报文本走 `msgSecCheck`。
- 图片：资产图片上传后走 `mediaCheckAsync`。
- 图片检测结果为高风险时，不允许后台审核通过。
- 图片检测仍在等待结果时，后台首次审核通过会被提示；管理员人工确认无问题后可以继续通过，但不能绕过明确高风险图片。

详细验证方法见 [content-safety-verification.md](./content-safety-verification.md)。

## 小程序端功能

### 1. 登录

入口：`登录` 页面。

用户需要填写微信昵称，可选择头像，然后点击“微信登录”。

登录后系统会保存：

- 微信用户身份
- 昵称
- 头像
- 信誉分
- 违规次数
- 是否封禁

小程序用户登录 token 有 30 天有效期，过期后需要重新走微信登录。

登录失败时，小程序会直接展示服务端返回的错误文案。若提交内容命中敏感信息，会提示用户“内容包含敏感信息，请修改后再提交”，不会误提示为登录失败。

### 2. 首页选择游戏

入口：底部 Tab `游戏`。

当前首页展示“塔防精灵”游戏入口。点击后进入该游戏的交换列表。

首页能力：

- 查看游戏入口。
- 查看未读价格变动提醒。
- 点击提醒进入消息通知。
- 通过页面按钮或微信右上角菜单分享首页。

### 3. 交换列表

入口：选择游戏后进入 `交换列表`。

列表主要展示进行中的交换信息。用户可以在顶部切换：

- 账号
- 道具

列表支持：

- 按标题、区服、描述搜索。
- 下拉刷新。
- 触底分页加载更多。
- 点击卡片进入详情页。
- 关注或取消关注某条信息。
- 分享当前列表，分享链接会保留游戏、资产类型和搜索词。

默认查询规则：

- 未输入关键词时，默认展示最近 7 天发布的数据。
- 输入关键词搜索时，默认查询最近 60 天数据。

列表每条信息展示：

- 标题
- 区服
- 类型
- 龙珠信息，若该资产是龙珠
- 主理人名称
- 当前价
- 截止时间
- 是否已关注
- 是否关联违规公示

价格展示规则：

- 如果已有出价，展示最新当前价。
- 如果没有出价，展示起始价。

### 4. 发布资产

入口：交换列表右上角 `发布账号` 或 `发布道具`。

发布信息会进入后台审核，审核通过后才会上架。

发布必填或核心字段：

- 主理人：必填，用户必须从可用主理人列表中选择。
- 区服。
- 交换标题。
- 宝贝描述。
- 起始价，单位为元宝。
- 最低加价，单位为元宝。
- 图片，最多 9 张，可不上传。

图片规则：

- 支持 JPG、PNG、WebP。
- 单张最大 5MB。
- 可以从相册选择或拍照。
- 账号图片和道具图片会写入不同上传路径，便于 Cloudflare 设置不同缓存或有效期。

发布道具时可以选择道具分类：

- 普通道具
- 龙珠

选择“龙珠”后需要填写：

| 字段 | 说明 |
| --- | --- |
| 职业 | 下拉选择：战士、法师、猎人、召唤、术士、牧师、熊猫、工程 |
| 品质 | 下拉选择：绿、蓝、紫、金、红 |
| 属性 | 输入龙珠属性，例如“附加伤害+10%，无视冰甲+5%” |

龙珠职业和系别映射：

| 系别 | 职业 |
| --- | --- |
| 暗 | 战士 |
| 冰 | 法师 |
| 雷 | 猎人 |
| 幻 | 召唤 |
| 魔 | 术士 |
| 木 | 牧师 |
| 光 | 熊猫 |
| 魂 | 工程 |

提交前会弹出免责声明，说明平台只提供信息交换，不涉及线上资金交易。用户确认后才会提交。

发布限制：

- 未登录用户不能发布。
- 被封禁用户不能发布。
- 信誉分 70 分及以下用户不能发布。
- 默认每个用户每天最多发布 3 条，后台可以为单个用户单独设置每日发布次数。
- 后台设置每日发布次数为 `0` 时，该用户不能发布。
- 文本命中内容安全风险时，不能提交。

### 5. 交换详情

入口：点击交换列表、我的发布、我的关注、我的出价或消息通知中的资产。

详情页展示：

- 标题
- 图片，支持点击预览
- 游戏、区服、资产类型
- 龙珠信息，若有
- 描述
- 卖家昵称
- 主理人名称和沟通提示
- 资产状态
- 当前价
- 最低加价
- 本次最低出价
- 截止时间
- 最近出价记录
- 是否关联违规公示

详情页支持分享，分享会携带资产 ID、标题、游戏名称和首张图片。

### 6. 提交估价

入口：交换详情页 `提交估价`。

用户输入出价金额后提交。系统会校验：

- 用户已登录。
- 用户未被封禁。
- 用户信誉分高于 70 分。
- 资产状态为已上架。
- 当前时间未超过截止时间。
- 出价金额必须达到“当前价 + 最低加价”。
- 不能对已结束、已下架、已驳回或非进行中的信息出价。

提交前会弹出免责声明。出价成功后，若小程序构建时配置了微信订阅消息模板 ID，小程序会请求“价格变动提醒”授权；用户拒绝授权不影响本次出价结果。

出价成功后：

- 当前价会更新。
- 详情页最近出价记录会刷新。
- 其他打开该详情页的用户会通过实时连接看到新出价。
- 被超过的历史出价用户会收到站内通知。
- 如果历史出价用户曾授权微信订阅消息，系统会尝试发送微信服务通知。

价格变动服务通知配置见 [wechat-price-change-subscribe-message.md](./wechat-price-change-subscribe-message.md)。

### 7. 关注信息

入口：交换列表卡片、我的关注。

用户可以关注已上架且未结束的信息。关注后：

- 列表按钮显示“已关注”。
- 信息会出现在个人中心的“我的关注”。
- 可以在列表或我的关注中取消关注。

限制：

- 未登录用户关注时会跳转登录。
- 被封禁用户不能关注。
- 信誉分 70 分及以下用户不能关注或取消关注。
- 非上架或已结束信息不可关注。

### 8. 消息通知

入口：

- 首页未读提醒
- 交换列表未读提醒
- 个人中心 `消息通知`

当前通知类型为价格变动提醒。当用户参与过的信息被别人出更高价时，系统会创建站内通知。

消息通知页支持：

- 查看未读数量。
- 查看通知资产标题、出价人、最新价格和时间。
- 点击通知进入资产详情。
- 点击未读通知时会尝试标记为已读。

如果标记已读失败，仍会继续跳转详情页。

### 9. 个人中心

入口：底部 Tab `我的`。

个人中心展示：

- 头像或昵称首字。
- 昵称。
- 当前信誉分。
- 违规记录数。
- 未读消息数量。

个人中心菜单：

| 菜单 | 功能 |
| --- | --- |
| 我的发布 | 查看自己提交的资产及审核状态 |
| 我的关注 | 查看关注过的信息，支持分页和取消关注 |
| 我的出价 | 查看自己参与过的出价和当前价 |
| 消息通知 | 查看价格变动提醒 |
| 成交记录 | 查看成交、流拍、取消、下架等结果记录 |
| 退出登录 | 清除本地登录态并返回登录页 |

### 10. 我的发布

展示用户自己发布过的资产，包括审核中、已上架、已结束、已驳回、已取消、已下架等状态。

列表展示：

- 图片首图或无图占位
- 标题
- 中文状态
- 游戏、区服
- 当前价
- 截止时间，已上架资产显示

点击记录可以进入资产详情。

### 11. 我的出价

展示用户参与过出价的资产。

列表展示：

- 资产标题
- 我的出价
- 当前价

点击记录可以进入资产详情。

### 12. 我的关注

展示用户关注过的信息，支持：

- 分页加载
- 下拉刷新
- 取消关注
- 点击进入详情

展示字段和交换列表基本一致，包括主理人、当前价、截止时间和龙珠信息。

### 13. 成交记录

展示和当前用户相关的结果记录：

- 已成交
- 已流拍
- 已取消
- 已下架

列表支持分页加载，并展示资产名称、游戏、区服、资产类型、成交价或未成交状态、记录时间。点击记录可进入资产详情。成交记录页不再额外弹出免责声明。

### 14. 举报入口说明

当前阶段小程序侧暂时不展示举报入口。后端举报接口和后台举报审核能力仍然保留，后续需要恢复时可重新接入小程序入口。

已有后端规则：

- 用户不能举报自己发布的信息。
- 举报必须关联具体资产。
- 只有参与过该资产出价的用户可以举报。
- 被封禁或信誉分 70 分及以下用户不能举报。

## 后台管理端功能

### 1. 登录与退出

入口：管理后台登录页。

后台用户输入用户名和密码登录。登录成功后，系统会按角色展示不同菜单。

同一 IP 和登录名连续输错密码会被短时限流。遇到限流时，需要稍后重试或请超级管理员确认账号状态。

退出登录会清除本地后台登录态，并返回登录页。

### 2. 后台角色权限

| 角色 | 可见页面 | 页面内主要能力 | 数据范围 |
| --- | --- | --- | --- |
| 超级管理员 `super_admin` | 仪表盘、审核管理、资产数据、后台用户、主理人管理、前台用户、系统配置 | 全量管理；审核/批量审核；扣信誉；处理举报；发布违规公示；下架/批量下架；导出；管理后台账号；绑定主理人；管理前台用户风控；维护系统配置 | 全部数据，包含未绑定主理人的历史数据 |
| 审核员 `reviewer` | 仪表盘、审核管理、资产数据 | 查看和导出资产；审核/批量审核待审核资产；扣减自己名下违规资产卖家信誉分；查看和处理自己名下举报 | 仅绑定主理人名下数据；未绑定可用主理人时列表为空，详情和操作返回无权限或不存在 |
| 运营 `operator` | 仪表盘、资产数据 | 查看和导出资产；下架/批量下架已上架资产 | 仅绑定主理人名下数据；未绑定可用主理人时列表为空，详情和操作返回无权限或不存在 |

后台侧边栏会按角色隐藏不可用页面。服务端接口也会再次鉴权，不能只依赖前端页面隐藏。

### 3. 仪表盘

可见角色：超级管理员、审核员、运营。

仪表盘展示平台运营概览：

- 待审核资产
- 进行中交换
- 待处理举报
- 封禁用户
- 总用户
- 今日新增用户
- 今日发布资产
- 今日出价

仪表盘还展示：

- 最新待审核资产，最多 5 条。
- 最新待处理举报，最多 5 条。

支持操作：

- 刷新数据。
- 点击资产标题或资产编号进入资产详情。
- 点击举报关联资产进入资产详情。

数据范围：

- 超级管理员看到全量。
- 审核员和运营只看到绑定主理人名下数据。

### 4. 审核管理

可见角色：超级管理员、审核员。

审核管理包含两个 Tab：

- 资产审核
- 举报审核

#### 4.1 资产审核

资产审核队列展示待审核资产，支持分页。

列表展示：

- 选择框
- 资产编号
- 图片缩略图和图片数量
- 资产标题
- 龙珠摘要，若有
- 游戏与区服
- 卖家 ID
- 起始价
- 提交时间
- 状态
- 操作

可执行操作：

- 查看详情：点击资产编号或标题进入资产详情。
- 预览图片：点击缩略图打开图片预览弹窗，图片可新窗口打开。
- 通过：审核通过后资产上架。
- 驳回：输入驳回原因后驳回资产。
- 扣信誉：输入扣减原因，对该资产发布者扣减 5 分信誉分。
- 全选本页。
- 清空选择。
- 批量通过。
- 批量驳回。
- 刷新。

审核通过后的截止时间规则：

- 资产审核通过时，系统会把实际截止时间设置为“审核通过时间 + 24 小时”。
- 小程序列表和详情展示这个实际截止时间。

图片安全注意事项：

- 图片检测为高风险时，不能审核通过。
- 图片检测仍在等待或检测失败时，首次通过会出现提示。
- 管理员人工确认图片无违规内容后，可以二次确认通过。
- 人工确认不能绕过明确高风险图片。

扣信誉注意事项：

- 应只对当前具体违规资产扣减，不要因为单个资产违规扩散到同一卖家其他资产。
- 扣减后用户信誉分减少 5 分。
- 用户信誉分 70 分及以下时，只能浏览，不能执行写操作。

#### 4.2 举报审核

当前小程序侧暂时不展示举报入口，但后台仍保留举报审核能力。

举报列表展示：

- 举报编号
- 被举报用户 ID
- 举报原因
- 举报人昵称和 ID
- 关联资产
- 证据
- 提交时间
- 状态
- 操作

可执行操作：

- 确认：确认举报成立。
- 公示：对已确认举报发布违规公示。
- 驳回：输入驳回原因后驳回举报。
- 点击关联资产进入资产详情。
- 分页查看。
- 刷新。

违规公示规则：

- 公示只关联具体资产。
- 小程序只在该具体资产列表和详情展示“该宝贝关联违规公示”。
- 不会把违规标签扩散到同一卖家的其他资产。

### 5. 资产数据

可见角色：超级管理员、审核员、运营。

资产数据页用于查看全部状态资产、筛选、导出和下架。

筛选条件：

- 关键词：资产编号、卖家 ID 或标题。
- 状态：默认、待审核、已上架、已结束、已拒绝、已取消、已移除、草稿。

- 停用账号。

- 分页查看。
- 刷新。

- 不能删除当前登录账号。

可见角色：超级管理员。

每日发布次数规则：

- 留空：使用系统默认值，当前默认 3 次。
- `0`：禁止发布。
- 正整数：该用户每天最多发布对应条数。

封禁规则：

- 封禁后用户不能发布信息、上传资产图片、出价或提交举报。
- 解封后，如果信誉分仍高于 70 分，用户可以恢复写操作。
- 解封不会自动恢复信誉分。

信誉分规则：

- 信誉分由资产审核或详情中的“扣信誉”触发。
- 信誉分 70 分及以下会用风险状态标记。
- 信誉分自动恢复由后端按 3 个月规则处理。

## 关键业务规则

### 资产状态

| 系统状态 | 中文展示 | 说明 |
| --- | --- | --- |
| `draft` | 草稿 | 暂存状态，当前小程序一般不展示 |
| `pending_review` | 审核中 / 待审核 | 用户已提交，等待后台审核 |
| `active` | 已上架 | 审核通过，可被浏览和出价 |
| `ended` | 已结束 | 到达截止时间或已完成结果结算 |
| `rejected` | 已驳回 / 已拒绝 | 后台审核未通过 |
| `cancelled` | 已取消 | 资产被取消 |
| `removed` | 已下架 / 已移除 | 后台下架，前台不可继续参与 |

### 截止时间

- 小程序发布页不让用户填写截止时间。
- 后端会保留数据库截止时间字段。
- 资产审核通过时，实际截止时间统一设置为审核通过后 24 小时。
- 小程序列表、关注列表、我的发布和详情页展示该实际截止时间。
- 截止时间过后不允许继续出价。
- 后端会在写入出价的事务中再次复核截止时间，避免临界时间绕过。

### 出价规则

- 只有已上架且未结束资产可以出价。
- 当前价为空时，最低出价为起始价。
- 当前价不为空时，最低出价为当前价加最低加价。
- 出价成功后，资产当前价和最高出价用户会更新。
- 出价后，旧出价用户会收到站内价格变动提醒。

### 结果记录

小程序“成交记录”展示和当前用户相关的结果，包括：

- 已成交
- 已流拍
- 已取消
- 已下架

系统不处理支付和交付，只记录交换结果状态。成交记录接口支持分页，并返回资产名称，便于用户识别具体宝贝。

### 数据权限隔离

后台数据权限按照主理人隔离：

- 超级管理员可以看全部。
- 审核员和运营只能看自己绑定主理人名下的数据。
- 没有绑定可用主理人的审核员或运营，列表返回空数据。
- 非授权范围内的详情和操作会返回无权限或不存在。
- 后端接口会做强制校验，不能通过直接请求 ID 绕过。

### 内容安全与审核

资产发布涉及两类安全检查：

- 文本内容安全：标题、描述、区服等文本会进入内容安全校验。
- 图片内容安全：图片上传后会异步检测。

审核建议：

1. 先查看文字、图片和价格是否正常。
2. 对图片尚未完成检测的资产，人工确认前不要通过。
3. 明确违规的资产应驳回，并可对发布者扣信誉。
4. 如果资产已上架后发现问题，应在资产数据页下架。

### 用户限制汇总

| 用户状态 | 浏览 | 发布 | 上传图片 | 关注/取消关注 | 出价 | 举报 | 标记通知已读 |
| --- | --- | --- | --- | --- | --- | --- | --- |
| 正常且信誉分高于 70 | 可以 | 可以 | 可以 | 可以 | 可以 | 可以，当前小程序入口暂不展示 | 可以 |
| 信誉分 70 分及以下 | 可以 | 不可以 | 不可以 | 不可以 | 不可以 | 不可以 | 不可以 |
| 已封禁 | 可以 | 不可以 | 不可以 | 不可以 | 不可以 | 不可以 | 视后端限制不可执行写操作 |

## 推荐运营流程

### 新增一个主理人

1. 超级管理员进入后台“后台用户”。
2. 创建后台登录账号，选择 `reviewer` 或 `operator`。
3. 在“关联主理人”中填写小程序展示名称。
4. 保存后进入“主理人管理”确认状态为“可选择”。
5. 通知该主理人使用后台账号登录。
6. 小程序用户发布时即可选择该主理人。

### 审核一条新资产

1. 后台进入“审核管理 -> 资产审核”。
2. 查看标题、描述、价格、图片和主理人归属。
3. 点击图片预览，确认图片内容。
4. 如信息正常，点击“通过”。
5. 如资料不完整或违规，点击“驳回”并填写原因。
6. 如确认违规，可点击“扣信誉”并填写原因。

### 下架已上架资产

1. 后台进入“资产数据”。
2. 使用状态、关键词、游戏或类型筛选资产。
3. 点击资产详情核对信息和出价记录。
4. 单条点击“下架”，或勾选多条已上架资产后“批量下架”。
5. 确认后资产前台不可见，不能继续出价。

### 处理风险用户

1. 超级管理员进入“前台用户”。
2. 搜索用户 ID 或昵称。
3. 查看信誉分、违规次数、封禁状态和每日发布次数。
4. 必要时设置每日发布次数为 `0`，或直接封禁。
5. 用户整改后可解封，但信誉分不会因为解封自动恢复。

### 导出资产数据

1. 进入“资产数据”。
2. 先设置筛选条件。
3. 点击“导出 Excel”。
4. 下载文件只包含当前角色有权限查看的数据。

## 常见问题

### 为什么小程序发布时必须选择主理人？

主理人决定该资产后续由谁审核和运营管理。为了避免资产没有归属，发布时主理人是必填项。

### 为什么审核员登录后看不到数据？

通常有两种原因：

- 该后台账号没有绑定可用主理人。
- 资产归属不是该账号绑定的主理人。

需要超级管理员到“后台用户”或“主理人管理”检查绑定关系。

### 为什么资产审核通过后截止时间不是用户填写的时间？

当前小程序已经隐藏截止时间字段。系统规则是资产审核通过后自动设置为 24 小时截止，保证每条上架信息都有完整曝光周期。

### 为什么图片还没检测完成也可以人工确认通过？

微信图片检测是异步回调，可能因为网络或回调延迟停留在等待状态。后台允许管理员在人工确认图片无问题后通过，但如果微信明确返回高风险，系统仍会阻止通过。

### 为什么用户不能继续出价？

常见原因：

- 资产不是已上架状态。
- 资产已经超过截止时间。
- 出价金额低于最低出价。
- 用户被封禁。
- 用户信誉分 70 分及以下。
- 用户登录态失效。

### 为什么用户没有收到微信服务通知？

微信服务通知依赖用户授权和模板配置。优先检查：

- 用户成功提交估价后是否允许订阅。
- 后端是否配置 `WECHAT_PRICE_CHANGE_SUBSCRIBE_TEMPLATE_ID`。
- 小程序构建时是否配置 `UNI_APP_PRICE_CHANGE_SUBSCRIBE_TEMPLATE_ID`。
- 小程序版本状态是否和 `WECHAT_SUBSCRIBE_MESSAGE_MINIPROGRAM_STATE` 一致。
- 用户是否被其他用户超价。

站内通知不依赖微信授权，即使微信服务通知失败，站内通知仍会保留。

### 为什么某个用户只有一个资产显示违规？

违规公示是宝贝级展示。只有被后台公示的具体举报关联资产会展示违规标签，不会扩散到该卖家的其他资产。
